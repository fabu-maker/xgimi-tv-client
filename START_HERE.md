# Aktueller Stand

Siehe [README](README.md) und [technischer Befund](docs/SMARTTUBE_BINGEBANG_AUDIT.md). Repository und Signierverfahren existieren bereits. Es ist keine erneute Einrichtung von GitHub oder Signatur-Secret erforderlich, solange der bestehende CI-Schlüssel verfügbar bleibt.

Version 0.6 ist ein Stand zur Geräteprüfung. Der Nachweis der realen Film-/Serienwiedergabe und des echten Kontos steht aus. Die automatische Testausführung und ihre Grenzen sind im zugehörigen GitHub-Actions-Lauf dokumentiert.
